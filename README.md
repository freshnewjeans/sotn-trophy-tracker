# Castlevania Requiem — Trophy Tracker

A beautiful macOS-style, light-mode trophy-hunting companion for **Castlevania: Symphony of the Night** and **Rondo of Blood** (from *Castlevania Requiem*), so you can get every trophy without missing anything.

## Features
- All **44 trophies** in play order, grouped into walkthrough phases
- Tick trophies as you earn them — progress saves in your browser (no login needed)
- Detailed **"How to unlock"** guide for every trophy
- **Map Guide** text (SOTN 200.6% + Rondo 100%)
- **Drawn schematic maps** — SOTN (normal + inverted) and Rondo stages, separated
- Light macOS theme, fully mobile-ready for iPhone Safari

## Use
Open `index.html` in any browser, or use the live GitHub Pages link.
